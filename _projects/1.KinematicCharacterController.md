<h3 class="project-section-title">프로젝트 개요</h3>
Unity Physics2D의 Rigidbody 이동과 Cast API에 의존하지 않고, 2D Kinematic 캐릭터의 이동과 충돌 처리를 직접 구현했습니다.
<br>
<br>

<h3 class="project-section-title">주요 작업 내용</h3>
- Shape Cast 및 충돌 체크 구현
  - Minkowski Sum으로 두 충돌 형상의 조합을 확장 형상으로 바꾸고, 이동 형상의 중심점을 Cast하는 방식 적용
  - 원 교차는 이차방정식, 박스 교차는 Slab 방식으로 계산하고, 원과 박스의 모서리는 Rounded Box로 처리
  - AABB 기반 Box와 Circle 충돌 구현
- 회전된 박스의 OBB Overlap 검사 구현
- Discrete 이동과 Sweep 이동 구현
  - Discrete: 이동을 적용한 뒤 겹침을 검사하고 MTV로 위치 보정
  - Sweep: 이동 경로에서 최초 접촉을 찾아 이동을 제한하고 남은 변위로 슬라이딩 처리
- 이동 우선순위 구현
  - 서로 다른 우선순위가 충돌하면 높은 우선순위 바디의 이동을 유지하고 낮은 우선순위 바디의 이동·위치를 조정
- 초기 겹침 보정 방식 구현
  - Instant: 충돌 계산 위치와 Transform 위치를 즉시 보정
  - Smooth: 충돌 계산 위치는 즉시 보정하고, 표시용 Transform 오프셋만 부드럽게 보정
- 정적 충돌 바디의 후보 조회를 위한 QuadTree 구현
